# Conway's game of life

It is a zero player game.
make initial configuration and run game.

### 4 rules
- Any live cell with fewer that 2 live neigbhors dies.
- Any live cell with 2 or 3 live neigbhors lives on to next generation.
- Any live cell with more than 3 live neigbhors dies.
- Any dead cell with exactly 3 live neigbhors becomes live.

### Types of cell during game
- still alive
- oscilators
- patters
- travelers
